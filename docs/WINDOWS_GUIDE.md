# VisualMap Windows 安装与使用说明

适用：0.1.0 公开测试版，Windows 10 / 11 64 位。开发者：Hyperdimensionalreference。

## 下载与安装

1. 打开项目的 [版本下载页](https://github.com/Hyperdimensionalreference/VisualMap/releases/tag/v0.1.0)。
2. 展开 Assets，下载 `VisualMap-0.1.0-Windows-x64-Setup.exe`。普通用户只需这个安装包，不需要下载源码或 ThirdParty.zip。
3. 双击安装包，阅读许可说明，选择安装目录并按向导安装。默认安装到当前用户的程序目录，不要求管理员权限。
4. 从开始菜单打开 **VisualMap**。程序会在默认浏览器中打开本机工作台；无需另装 Python，也无需注册账号。

安装包包含 CPU 运行环境、YOLOX 离线识别模型、字体及第三方许可和必要源码，首次使用不需要下载模型。此公开版不内置 GroundingDINO / CLIP 扩展模型；历史量化模型的独立分发授权尚未明确。扩展接口代码仍在源码中，但不应把本版描述成三模型版。

本版尚未进行 Authenticode 代码签名，不能提供证书验证的发布者身份。请只从上述项目下载页获取文件，并核对同一页面的 `SHA256SUMS.txt`。PowerShell 校验方法：

```powershell
Get-FileHash -Algorithm SHA256 .\VisualMap-0.1.0-Windows-x64-Setup.exe
```

将结果与校验文件中的安装包一行比较，应完全一致。哈希只能确认文件一致性，不能代替恶意软件检查。安全软件若提示威胁，请停止安装或运行，保留检测名称、文件名与 SHA-256，联系安全厂商复核；不要关闭防护、加入白名单或改名绕过提示。反馈时遮住个人路径、账号及其他私人信息。

## 第一次识别

1. 准备一段自己有权使用的短视频，建议先试 5～30 秒。光线充足、画面清晰、缓慢横向移动相机会更有利于三维跟踪；纯旋转、纯色墙面、模糊、反光和快速运动容易失败。
2. 点击 **导入视频** 或把视频拖进上传区。界面支持选择 MP4、MOV、AVI、MKV、WebM，单文件上限 2 GB；具体能否解码仍取决于文件编码，手机 HEVC 等编码可能需要先转为常见的 H.264 MP4。原文件不应被覆盖。
3. 预览后点击 **保存并识别**。如果只想存入库中，选择 **仅保存到视频库**，稍后从该视频详情启动识别。
4. 等待实际处理进度。CPU 处理长视频可能较慢，不要在处理中退出、升级或卸载。
5. 完成后点击 **打开三维空间**。在视频详情中也可以重新打开已保存的每次结果；原始视频仍可回看。

## 怎么理解三维结果

结果包含相机轨迹、稀疏地图点、检测框、物体观测和可核对的空间证据。按页面提示拖动、缩放视图，并结合原视频检查物体类别与位置。

YOLOX 以其训练类别进行检测，不能保证识别任意物品、品牌或细小设备。缺少足够几何证据时，二维识别不一定会生成三维位置；没有轨迹或地图点可能是场景不可观测，不能据此编造空间。

距离单位是未标定的 `map_units`，不能当成米或厘米。体积属于估计，跟踪覆盖率、模型分数和多帧一致性也都不等于识别准确率。本版用于研究和学习，不用于碰撞安全认证或精密测量。

## 可选：让大模型复核选定画面

这一步需要自己配置支持多图的 OpenAI 兼容视觉 API，可能由服务商收费。基础离线识别不需要 API Key。

1. 在侧栏的 **大模型设置** 中填写服务商的 HTTPS API 地址、支持图片的模型名和自己的 API Key。不要填写到 GitHub issue、截图或公开配置中。
2. 默认可选 **仅本次服务运行期间使用**；如需持久保存，可选 **使用 Windows 加密保存到本机**。加密不可用时应按界面错误处理，不要改为明文文件保存。
3. 从结果页进入复核功能，选择同一物体的三个不同时间画面并框出目标，填写问题，检查选图后再手动发送。
4. 只有这次明确发送才会向配置的服务方提交三张裁剪图、问题及相应帧/时间信息。保存设置和打开页面不会自动调用模型。返回内容可能错误，应结合原图判断后再确认名称；可以撤销确认。

完整传输与保存范围见 [隐私说明](../PRIVACY.md)。请勿在未获同意时发送含人脸、住址、证件或他人隐私的画面。

## 数据、退出、升级与卸载

安装目录保存程序、运行库和模型。个人视频、识别历史和设置默认保存在 `%LOCALAPPDATA%\VisualMap`；不要把这个个人数据目录一起分享。导入和结果副本会额外占用磁盘，长视频需要留出足够空间。

关闭浏览器窗口后，本机服务仍可能运行。请等识别和复核结束，再从开始菜单点击 **退出 VisualMap**。重开 VisualMap 后可继续查看历史。

视频库的回收站支持恢复；永久删除需要明确确认。存储整理会处理内容相同的托管视频副本以及可无损压缩的结果，不会重新压缩原视频。重要素材仍应另行备份。

升级前先退出服务并备份个人数据，再运行新安装包。Windows 的“已安装的应用”或开始菜单可以卸载；默认保留个人数据，以便重装继续使用。如果确实不再需要数据，应先备份、退出程序，再自行核对并删除个人数据目录。不要把程序目录与个人数据目录混淆。

## 常见问题

| 现象 | 建议 |
|---|---|
| 没有自动打开浏览器 | 尝试访问 `http://127.0.0.1:8765/`；检查本机是否已有其他工作台占用端口。不要把本机端口转发到互联网。 |
| 已有源码版或另一份程序在运行 | 完成其任务后正常退出，再启动安装版。程序不会强制终止另一个工作区。 |
| 导入成功但识别失败 | 查看界面错误，先用短而清晰的视频重试。文件后缀被支持不代表所有编码均可解码。 |
| 有检测框但三维为空 | 检查拍摄移动、纹理、清晰度和几何证据；单目视频并非总能恢复空间。 |
| 漏检或类别不准 | 核对原视频。当前内置 YOLOX 的类别与能力有限，可选择手动三图复核。 |
| API 报错 | 检查 HTTPS 地址、模型是否支持多图、密钥权限和余额。重试会再次请求服务，可能再次计费。 |
| 安全软件报警 | 停止运行并保留检测信息，请厂商复核；不要关闭防护或绕过拦截。 |

需要另选本机端口时，可在安装目录运行：

```powershell
.\VisualMap.exe --port 8766
```

任务结束后可用同一程序和端口退出：

```powershell
.\VisualMap.exe --stop --port 8766
```
